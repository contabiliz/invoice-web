# Spec 01.4 — Auth: Tratamento de Erros e i18n

> **PRD:** PRD-01 §01.3.2, §01.8, §01.13
> **Última atualização:** 2026-04-04

---

## 1. Princípio

O campo `error.message` retornado pelo Supabase Auth é uma string em inglês, técnica, não destinada ao usuário final. **Nunca exibir ao usuário.** Todo erro é mapeado para uma chave i18n e resolvido via `useTranslations('auth')`.

---

## 2. Função de mapeamento

```ts
// src/lib/auth/errors.ts
import type { AuthError } from "@supabase/supabase-js";

/**
 * Mapeia AuthError do Supabase para chave i18n do namespace 'auth'.
 * Retorna sempre uma chave válida — nunca expõe error.message ao caller.
 */
export function mapSupabaseAuthError(error: AuthError): string {
  // Erros de credencial / conta
  if (error.message.includes("Invalid login credentials")) {
    return "errors.invalid_credentials";
  }
  if (error.message.includes("Email not confirmed")) {
    return "errors.email_not_confirmed";
  }
  if (
    error.message.includes("User already registered") ||
    error.message.includes("already been registered")
  ) {
    return "errors.email_already_registered";
  }

  // Erros de senha (retornados pelo Supabase antes de criar a conta)
  if (
    error.message.includes("Password should be at least") ||
    error.message.includes("password")
  ) {
    return "errors.password_too_short";
  }

  // Rate limiting
  if (error.status === 429) {
    return "errors.rate_limited";
  }

  // Erros de rede / servidor
  if (!error.status || error.status >= 500) {
    return "errors.server_error";
  }

  // Fallback genérico
  return "errors.unexpected";
}
```

**Por que `includes` ao invés de comparação exata:**
O Supabase Auth pode variar ligeiramente as mensagens de erro entre versões (`"Password should be at least 6 characters"` vs `"Password should be at least 8 characters"`). Matching por substring é mais resiliente a atualizações de patch.

## 4. Separação: erros de validação vs erros de submit

| Tipo | Origem | Onde exibir | Componente |
|---|---|---|---|
| Validação Zod | `formState.errors` do RHF | Inline abaixo do campo | texto `<p role="alert">` |
| Erro de submit | `mapSupabaseAuthError()` | Banner acima do formulário ou abaixo do botão | `AuthErrorBanner` |

**Regra:** erros de validação nunca aparecem no banner. Erros de submit nunca aparecem inline no campo.

## 5. Cenários de erro mapeados

### Login

| Cenário | `error.message` Supabase | Chave i18n | Mensagem PT-BR |
|---|---|---|---|
| Email ou senha errados | `Invalid login credentials` | `errors.invalid_credentials` | "Email ou senha incorretos. Verifique os dados e tente novamente." |
| Email não confirmado | `Email not confirmed` | `errors.email_not_confirmed` | "Confirme seu email antes de entrar." |
| Rate limit | status 429 | `errors.rate_limited` | "Muitas tentativas. Aguarde alguns minutos e tente novamente." |
| Servidor indisponível | status 5xx | `errors.server_error` | "Não foi possível conectar ao servidor. Tente novamente." |
| Qualquer outro | — | `errors.unexpected` | "Ocorreu um erro inesperado. Tente novamente." |

### Cadastro

| Cenário | `error.message` Supabase | Chave i18n | Mensagem PT-BR |
|---|---|---|---|
| Email já cadastrado | `User already registered` | `errors.email_already_registered` | "Este email já está cadastrado. Tente fazer login." |
| Senha muito fraca | `Password should be at least...` | `errors.password_too_short` | "A senha deve ter pelo menos 8 caracteres." |
| Rate limit | status 429 | `errors.rate_limited` | "Muitas tentativas. Aguarde alguns minutos e tente novamente." |
| Servidor indisponível | status 5xx | `errors.server_error` | "Não foi possível conectar ao servidor. Tente novamente." |

### Validação local (antes do submit)

| Campo | Regra Zod | Chave i18n | Mensagem PT-BR |
|---|---|---|---|
| Email | `.email()` | `validation.email_invalid` | "Email inválido." |
| Senha (login) | `.min(1)` | `validation.password_required` | "Senha obrigatória." |
| Senha (cadastro) | `.min(8)` | `validation.password_too_short` | "A senha deve ter pelo menos 8 caracteres." |
| Confirmar senha | `.min(1)` | `validation.confirm_required` | "Confirme sua senha." |
| Senhas diferentes | `.refine()` | `validation.passwords_mismatch` | "As senhas não coincidem." |

## 6. O que não logar

```ts
// ❌ NUNCA fazer isso
console.log("Auth error:", error.message); // expõe detalhes técnicos
console.log("User email:", values.email);  // PII em logs do browser
console.log("Password:", values.password); // credencial em texto claro

// ✅ Logar apenas código de status para debug
if (process.env.NODE_ENV === "development") {
  console.warn("[auth] signIn failed:", error.status);
}
```

Em produção, não logar nada relacionado à autenticação no console do browser.
